---------------------------------------------------------------------------------------------------
Version: 0.1.9
Date: 2026-11-15
  Optimizations:
    - Far fewer API calls per drone per tick: sprite scale and tilt are only written when they change (never, with real bank frames), and render objects are checked for validity once a second and on every redraw instead of every tick.
---------------------------------------------------------------------------------------------------
Version: 0.1.8
Date: 2026-11-15
  Bugfixes:
    - Fixed drones crawling at minimum speed for the whole flight when their cruise speed was below
      about 12 tiles/s: the takeoff and approach speed blends overshot below zero. Slow drones now
      fly at their cruise speed.
---------------------------------------------------------------------------------------------------
Version: 0.1.7
Date: 2026-11-15
  Optimizations:
    - Flights marked hidden (f.hidden = true, for culling) skip all render object updates while still flying.
    - Hidden map dots are no longer moved, and a shown map dot's validity is only checked on the ticks it moves.
    - Fewer temporary tables each tick.
---------------------------------------------------------------------------------------------------
Version: 0.1.6
Date: 2026-11-15
  Features:
    - Flight.fly_to_pad options first_turn and last_turn ("L"/"R"): make the path start and/or end with a turn that way. Both "R" puts departures and arrivals on opposite circles around each pad, like an airport traffic pattern. Falls back to fewer constraints if a combination can't reach.
---------------------------------------------------------------------------------------------------
Version: 0.1.5
Date: 2026-11-13
  Features:
    - Flight.orbit options: first_turn ("L"/"R") makes the path start with a turn that way; entry_spread picks a random entry point among those almost as short as the best, so a group doesn't all fly the same line in.
    - Flight.fly_to option first_turn.
  Changes:
    - Tight arcs get more path points (at least one per 0.08 rad), so they turn and bank smoothly instead of in small steps.
---------------------------------------------------------------------------------------------------
Version: 0.1.4
Date: 2026-11-13
  Bugfixes:
    - A follower that gets ahead of its slot no longer loops back around to it. It eases off to half speed and lets the formation catch up.
---------------------------------------------------------------------------------------------------
Version: 0.1.3
Date: 2026-11-13
  Changes:
    - Followers steer like planes: they keep moving and turn no tighter than follow_turn_radius (6 tiles), so a wingman joining from the wrong direction swings round in an arc instead of snapping around.
---------------------------------------------------------------------------------------------------
Version: 0.1.2
Date: 2026-11-13
  Bugfixes:
    - Fixed heading and bank frames flickering back and forth in tight turns and formation flying: a frame now only changes once the drone is clearly past the halfway point to the next one.
---------------------------------------------------------------------------------------------------
Version: 0.1.1
Date: 2026-11-13
  Features:
    - split_banks option: one animation per bank ("<name>-0", "<name>-1", ...), since Factorio animations can't have more than 255 frames.
---------------------------------------------------------------------------------------------------
Version: 0.1.0
Date: 2026-11-13
  Features:
    - First release. Flight code from Long Haul Logistics 1.0.2: runway takeoffs and landings, turn-radius paths, speed and altitude profiles, shadows, squeeze banking, map dots and flying sounds.
    - Circling: fly to the best entry point on a circle, then orbit it.
    - Formation flying: followers hold "V" slots behind a leader.
    - Real bank frames (frame = bank * headings + heading), plus an optional glow layer.
